# Inventory Management System (Java)

## 📌 Project Description
The Inventory Management System is a simple Java console-based application designed to manage and maintain product stock efficiently. It allows users to add, remove, and view inventory items with details such as item name, quantity, and price.

## 🚀 Features
- Add new items to the inventory.
- Remove existing items by item name.
- View all available inventory items.
- Display item details, including name, quantity, and price.
- Handle errors using exception handling.
- Simple menu-driven console interface.

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Generics
- ArrayList
- Collections Framework
- Exception Handling
- Scanner Class

## 📂 Project Structure

```text
InventoryManagementSystem/
│
└── src/
    └── com/
        └── inventory/
            ├── Item.java
            ├── Inventory.java
            └── InventorySystem.java
```

## 📖 Class Description

### 1. Item.java
Represents an inventory item with:
- Item name
- Quantity
- Price

### 2. Inventory.java
Manages inventory operations:
- Add items
- Remove items
- Display all items
- Maintain the item list using ArrayList and Generics.

### 3. InventorySystem.java
Main class of the application. Provides a menu-driven interface and accepts user input using the Scanner class.

## ⚙️ How to Run the Project

1. Install JDK on your computer.
2. Open Eclipse, IntelliJ IDEA, or VS Code.
3. Create a Java project named `InventoryManagementSystem`.
4. Create the package `com.inventory`.
5. Add the three Java files:
   - Item.java
   - Inventory.java
   - InventorySystem.java
6. Run `InventorySystem.java`.
7. Select the required option from the console menu.
